まくら投げ戦術ボード PWA Ver.0.56

【Ver.0.56 追加機能】
- 大会ごとにメンバーセットを作成・複製・名称変更・削除できます。
- 同じメンバーセットを使う戦術へ、選手情報の変更が共通反映されます。
- 自チームと相手チームに名前・ゼッケン番号（2文字まで）と利き腕（右・左・両）を登録できます。
- 利き腕は盤面と共有PNGに側面ラインで表示されます。
- 共有シートを利用できない環境ではPNG保存へ切り替わります。
- 左利きは青線、両利きは左右の紫線で表示します。向かい合う相手チームの左利き線は画面右側へ表示します。
- セット編成は自チーム／相手チームのタブ式です。閉じる・完了は上部に固定しています。
- 並び替えは三本線だけから開始し、名前入力中の誤ドラッグを防ぎます。
- 自チーム・相手チームとも出場8枠＋控え2枠を同じ構成で管理できます。
- 戦術一覧は大会メンバーセットごとに整理され、盤面と共有PNGにもセット名を表示します。

このフォルダはそのまま静的Webサイトとして公開できます。

【含まれるファイル】
index.html
manifest.webmanifest
sw.js
icons/
.nojekyll

【重要】
PWAのオフライン機能は、file:// で直接開くだけでは動きません。
HTTPSで公開したURL（例：GitHub Pages）から一度開いてください。

【iPhone / iPad】
1. 公開URLをSafariで開く
2. 共有ボタン
3. 「ホーム画面に追加」
4. 追加した「まくら戦術」から起動
5. 一度オンラインで起動した後は、アプリ本体はオフラインでも起動できます

【Mac】
公開URLをSafariで開いて使用できます。
対応OSではSafariの「Dockに追加」も利用できます。

【データ】
戦術・メンバー情報はブラウザのlocalStorageへ保存します。
Googleログイン時はFirebase Cloud Firestoreにも保存され、同じGoogleアカウントのiPhone / iPad / Mac間で同期できます。
